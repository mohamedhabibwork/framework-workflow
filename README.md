# @framework/workflow

Multi-stage, multi-step resumable workflow engine with policies and persistence.

> **Read-only subtree split** — This package is developed inside the main [**mohamedhabibwork/framework**](https://github.com/mohamedhabibwork/framework/tree/main/packages/workflow) monorepo and automatically synced to [`mohamedhabibwork/framework-workflow`](https://github.com/mohamedhabibwork/framework-workflow). Please open issues and pull requests in the main framework repository.

## Installation

### Inside a Standalone App (via GitHub)

```json
{
  "dependencies": {
    "@framework/workflow": "github:mohamedhabibwork/framework-workflow"
  }
}
```

```sh
bun install
```

### Creating a New Application

Use the starter application template repository to bootstrap a full application with all framework packages pre-wired:

```sh
gh repo create my-api --template mohamedhabibwork/framework-app --clone
cd my-api
bun install
```
